# What's new in OQP Studio

## Available downloads

[Studio 0.2.3](download.md) remains the publicly available desktop release.
Its existing Windows, macOS and Linux downloads remain accessible while
independent Studio distribution is prepared.

## Independent releases

Future entries here will describe changes in the released **Studio** version,
the included **OpenQP** version and exact engine commit, supported platforms,
and upgrade notes. Stable and Preview releases will be clearly separated.

Features on the development branch are not announced as released until their
platform builds and compatibility checks have passed and the corresponding
installers are published. For current interface documentation, return to the
[Studio manual](index.md).
